# 木与光 · 可编辑装修模拟器

Angular 22 + Three.js，显式使用 WebGL2。两套独立 Blender / GLB 户型模型，顶部下拉框切换。

- 方案一：保留原方案、12 个空间、121 组家具，光厅仅加可移动绿植。
- 方案二：按新增平面图重建户内空间，11 个空间、78 组家具；不包含电梯间、楼梯间、入户光厅。延续白色沙发、蛋黄单椅、黑色正方茶几、淡蓝岛台与不锈钢厨房台面。
- 方案二修订 2：电视后增加约 3.4m 长的整排白柜；手工区与次卧之间开白框玻璃内窗（宽约 1.02m、高 1.20m、窗台高 1.10m），次卧相邻柜体改为 0.88m 高窗下柜；补回厨房北侧的玄关凹位、地面、墙体与 L 形收纳柜。尺寸为模型估算。
- 家具布置和房间状态分别自动保存，刷新后恢复上次选中的方案。切换不会覆盖另一套存档；撤销历史只针对当前加载的方案。
- 两套方案的窗外均加入 7 棵大树（南侧 4 棵、北侧 3 棵），仅在“第一人称漫游”时显示；自由查看、户型图、房间空间视角及室内视角均隐藏。退出漫游立即隐藏，清水房状态下进入漫游仍可看到树冠。
- 导出文件名包含方案名称；导入 JSON 时需切换至对应户型，错误户型的文件会被拒绝且不修改当前布置。

## 使用

- 右上角依次是“自由查看”“户型图”“第一人称漫游”；左侧保留各房间导航。每间房另有空间视角和室内视角。
- 左侧眼睛控制房间可见性，座椅按钮控制该房间装修。
- 底部“隐藏最近墙面”左侧是“锁定物件”，默认关闭。开启后取消当前选择，画面和家具清单都不能选中家具，也暂停添加和拖动；镜头仍可旋转、平移与缩放。关闭后恢复操作。锁定作为临时浏览状态在两套方案切换时保持，刷新网页恢复不锁定，不改动家具存档。
- “清水房”隐藏家具、柜体、灯具、软装和地面面层，墙体改为水泥基底；门窗与结构保留。
- “隐藏最近墙面”只移除当前视线首先遇到的一组墙及关联窗框、横梁，保留后方墙体。旋转或平移视角后重新选择最近墙面，不会逐层剥除远墙。俯瞰视角按视线的平面投影判断；平面图墙体裁切至低位。
- 天花板默认不显示，独立使用“显示天花板”开关；关闭自动隐藏墙面也不会打开天花板。平面图始终隐藏天花板。
- 编辑模式下直接拖动家具，按 5 cm 网格吸附；空白处左键拖动旋转视角。按住鼠标中键或右键拖动平移，滚轮缩放；中键拖动不会移动家具。
- 点击画面右上角“第一人称漫游”，每次固定从当前方案的入户门外开始、面向屋内，按 W 可穿过门洞进入玄关；不受此前查看哪个房间影响。视线高度 160 cm，W/S 前进后退、A/D 左右平移，鼠标转向；速度固定为 2.8 米/秒，Shift 不改变速度。Esc 退出并恢复进入前的视角。两套方案都可使用。
- 漫游时提供门外的小块落脚地面并连通门槛处楼板，仅用于进门浏览，不扩建方案二忽略的光厅或公共区域；退出漫游后隐藏。
- 漫游期间暂停家具选择和拖动、保留完整墙面；退出后恢复原来的墙面隐藏设置，天花板开关保持原状。支持墙体、窗户及户型边界阻挡和沿墙滑行；门洞可通行，家具和门扇暂不做碰撞，便于查看布局。
- 浏览器若不支持或拒绝锁定鼠标，会显示提示并改用左键拖动转向；仍支持 WASD。切出窗口或标签页会清除移动按键，切换方案会退出漫游。该模式使用键盘与鼠标，手机仍可使用原有触控浏览。
- 点击家具后可调整 X / Z 坐标、旋转、比例、配色，复制或删除。选择任一部件都会选中整件家具：洞洞板包含 56 个孔点；冰箱包含柜体、门面与分缝；灯具、电视、窗帘等同样整体操作。两把办公椅与三盆光厅绿植各自独立。
- 12 款内置样式涵盖沙发、单椅、方茶几、圆餐桌、床、斗柜、绿植，点击添加或拖入空间。
- Ctrl/⌘ + Z 撤销，Ctrl/⌘ + Shift + Z 重做，Delete 删除；保留最近 60 次操作。
- 当前布置自动保存至当前浏览器同一网址下的 localStorage。JSON 导出/导入适用于本模型版本，可长期备份。
- 方案二旧存档和 JSON 自动升级至 modelRevision 2，补上两组新柜；已有家具的移动、复制、删除、颜色及房间状态保留。未移动的电视与洞洞板会调整到新的默认位置，手动移动过的物件保持原位。升级前的自动存档备份在原存储键后加 `:before-model-revision-2`，更新后的存档不会重复添加柜子。
- 家具分组修订版使用 JSON 格式 v2，旧版 v1 方案自动整合。旧部件的位置、角度、比例会转换为完整家具的变换；复制过的零件会成为完整家具副本。如果同一家具多个旧部件各自有冲突编辑，优先采用已编辑的主体，再采用其他已编辑部件的变换。原自动存档保留备份，右侧可下载；原有独立家具、样式库家具和房间开关会保留。
- “导出当前 GLB”保存当前位置、旋转、缩放、配色及房间显隐状态；自动遮挡墙不会被误当作删除。完整顶板会重新纳入 GLB。
- “恢复初始布置”可撤销。纯本地静态应用，无账号、云同步或后台服务。

## 开发和构建

需要 Node.js 24.15+（或依 Angular 22 官方支持版本）。

~~~powershell
npm ci
npm run build
node serve.mjs dist/home-viewer/browser 8787
~~~

打开 http://127.0.0.1:8787/ 。不能直接双击 HTML：ES 模块和模型加载需要 HTTP 静态服务。

开发调试：npm start。生产输出目录：dist/home-viewer/browser。整个目录可放入任意 HTTP 静态服务器，也支持子目录部署。依赖和纹理均随包提供，运行时不依赖 CDN。

## 模型

- 独立模型：public/assets/home.glb（单位米，Y 轴向上）。
- 分组与相机：public/assets/project.json。
- 最新原图：public/assets/latest-plan.png。
- 方案二资源：public/assets/scheme-b/{home.glb, project.json, plan.png}；模型版本为 2026-09-14-plan-b。
- 共用窗外树冠资源：public/assets/exterior.glb，由 build_exterior_trees.py 在 Blender 中生成并同步写入两套原生 .blend 文件；更新户型模型后再执行此脚本。树冠独立于家具、房间装修和自动墙面隐藏，不写入家具存档；导出当前 GLB 会包含树木。
- 方案一继续使用 home-simulator:2026-09-14:v1 存储键，方案二使用 home-simulator:scheme-b:2026-09-14:v2；两套模型不共享家具 ID。
- build_scheme_b.py 以方案一的可编辑 .blend 为家具来源，仅复制完整物件并重建建筑；原文件不会被修改。放置坐标、来源和旋转记录在 scheme-b/placement-audit.json。
- 构件 extras：room、rooms、layer、cutaway。
- 可编辑家具 extras：entityId、entityName；浏览器创建独立父组作为物件旋转与移动中心。
- componentNames 记录构件归属；project.json 的 assemblies 明确定义 121 个完整物件、legacyEntities 记录旧版 188 组零件的原始旋转中心，供旧存档迁移。所有构件只属于一个完整物件，共保留 176050 个家具三角面。
- 源 .blend 另附；prepare_web_model.py 基于原 v2 场景更新并重新导出。输出保留原模型的可编辑对象，导出时烘焙程序化基础颜色并合并同一物件构件。

## 设计表达范围

最新图未标尺寸，比例沿既有模型约 58.8 px/m；层高 3m。主卧调整为东侧床头、西侧衣柜；主卫分为坐便、淋浴、短浴缸及洗漱区。厨房根据最新平面采用 U 形操作区，窗边水槽，左侧灶台、回转处电器立柜与不锈钢台面。

方案二未标尺寸，参照同户型约 47 px/m 估算，层高同为 3m；次卫北侧狭长空间暂按淋浴家政区表达，图中卧室外的椅形符号按梳妆座椅表达。具体用途与尺寸需深化确认。主卫改为钻石淋浴房、坐便和洗漱柜，家具按新图位置布置。

清水房水泥颜色、盆栽与三维家具为方案表达；不是现场测绘或图片生成效果图的完整复刻。墙体暂不支持拖改，未实现结构检查、家具碰撞约束、设备净空校验、预算计算或自定义外部家具模型导入。模型中既有收纳与隐藏床备选构件仍需深化尺寸。

## 验证

~~~powershell
npm run test:walls
# 先按上方命令启动静态服务器
npm run test:viewer
# 完整家具操作与旧存档迁移回归（默认访问 8788，可通过 VIEWER_URL 指定）
node tests/assemblies.cjs
# 两套方案保存隔离、刷新恢复、跨户型导入保护、导航、GLB 和手机切换
node tests/schemes.cjs
# 方案二柜体、室内窗、玄关凹位与修订前存档升级
node tests/scheme-b-update.cjs
# 窗外树冠加载、视图切换、存档保持和 GLB 导出
node tests/exterior.cjs
# 漫游移动、碰撞几何，以及实际键鼠 / 指针锁定 / 退出恢复 / 降级控制
npm run test:walk
npm run test:roaming
~~~

7 项几何回归验证最近墙选择、远墙保留和反向视角；22 项 Edge / Playwright 检查覆盖 WebGL2、12 个空间导航、旋转后恢复远墙、天花板独立开关、平面和透视视图的中键平移、家具编辑、JSON/GLB 导出、导入、刷新恢复与移动端。中键测试也核对所有家具位置不变。

参考：[Angular 静态部署](https://angular.dev/tools/cli/deployment)、[Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)。
